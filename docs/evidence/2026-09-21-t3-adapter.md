## Checks run

`bun run enroll:t3` used the setup credential once to mint a separate service token. The resulting session reported exactly `orchestration:read` and `orchestration:operate`. A request to `/api/auth/clients` with that token returned HTTP `403`. The secret file and its parent reported modes `0600` and `0700`. No credential is stored in the repository or evidence. The headless bootstrap code in the server startup log was checked after enrollment and reported `authenticated: false`.

`bun run test:t3` ran against the release binary. Six tests passed:

1. The adapter minted a WebSocket ticket, completed the Effect RPC handshake, called `server.probe`, decoded `server.getConfig`, and projected provider/model capability data.
2. The adapter sent the same `project.create` command twice with one stable command ID. T3 returned the same receipt sequence both times. The test then deleted the T3 project and removed its temporary directory.
3. The adapter created an isolated Git fixture, selected `codex` with `gpt-5.6-sol` in `approval-required` mode, completed a tool-free provider turn, replayed thread events to the synchronization marker, and reconciled the authenticated HTTP snapshot. The snapshot held the explicit provider/model, a completed latest turn, and the exact non-streaming assistant reply.
4. A second supervised turn requested command approval before reading its fixture. The test responded to each distinct request with one-shot `accept`, observed the requests resolve, received the exact file content, and removed the temporary project and repository.
5. A durable SQLite operation flowed through the production coordinator. After T3 accepted the turn, a forced bridge failure returned the operation to its durable pending state. The test closed and reopened SQLite, constructed a new worker, replayed the stable IDs, reconciled the completed snapshot, and atomically committed the operation plus its exact Slack outbox reply.
6. A supervised command was declined and the turn settled with no pending approval. A separate turn was interrupted while waiting for approval and reached the distinct `interrupted` state.
