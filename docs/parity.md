# Parity with Claude Tag

This page compares Agent Tag with [Claude Tag](https://claude.com/docs/claude-tag/users/getting-started), one behaviour per row, as `main` ships it today. `same` means a Slack user or operator sees the same behaviour. `deviation` means Agent Tag differs on purpose, and the last column says why. `not planned` means Agent Tag does not do it and no v0.1.0 spec plans it.

Claude Tag is in public beta, so its pages may change. Each row links the page it was taken from, read on 2026-10-21. Spec IDs such as `PR-F R1` or `PR-K §1.2` are the design specs cited in the [GA matrix](ga-acceptance.md). Work that is still in review is marked as planned, with its PR.

The security deviations ISO-01, ISO-02, TOOL-01 and AMB-01 are proposed as `OUT-OF-SCOPE` for v0.1.0, pending owner decision O-1. [SECURITY.md](../SECURITY.md#what-agent-tag-does-not-guarantee-compared-with-claude-tag) explains each one.
